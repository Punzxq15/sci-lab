# Sci-Lab: ภารกิจห้องทดลองอวกาศ (Python Dictionary)

เว็บเกมลากวาง (Drag & Drop) สอน Dictionary ภาษา Python — ใช้ได้ทั้ง PC และมือถือ

## โครงสร้างไฟล์
- index.html — หน้านักเรียน (ล็อกอิน, เกม, หน้าสรุปอันดับ)
- teacher.html — ห้องควบคุมครู (กดไอคอนคนสีเทามุมบนซ้ายของหน้าแรก)
- css/style.css — ธีมน้ำเงิน-ดำ-แดง
- js/config.js — ตั้งค่า API_URL, รายชื่อชั้น, จำนวนหัวใจ
- js/levels.js — เนื้อหาด่านทั้งหมด (แก้โจทย์ได้)
- js/game.js, js/teacher.js, js/api.js, js/audio.js, js/fx.js
- apps-script/Code.gs — แบ็กเอนด์ Google Apps Script

## วิธีติดตั้ง
1. สร้าง Google Sheet ใหม่ (เป็น "ชีตหลัก" เก็บห้อง/รายชื่อ/ความคืบหน้า)
2. Extensions > Apps Script > วางโค้ดจาก apps-script/Code.gs > บันทึก
3. (แนะนำ) Project Settings > Script properties > เพิ่ม TEACHER_PASSWORD = รหัสผ่านของคุณ (ค่าเริ่มต้น 1234)
4. Deploy > New deployment > Web app: Execute as = Me, Who has access = Anyone > อนุญาตสิทธิ์ (Sheets/Drive) > คัดลอก URL (ลงท้าย /exec)
5. วาง URL ใน js/config.js ที่ API_URL
6. อัปโหลดโฟลเดอร์เว็บขึ้นโฮสต์ฟรี เช่น GitHub Pages / Netlify / Cloudflare Pages (นักเรียนเปิดลิงก์เดียวกัน)
7. ถ้าแก้ Code.gs ภายหลัง ต้อง Deploy > Manage deployments > New version

## ขั้นตอนการสอน
1. ครูเข้า teacher.html > ใส่รหัสผ่าน > แท็บ "รายชื่อนักเรียน" วางรายชื่อของชั้น (ทำครั้งเดียว)
2. แท็บ "ห้องเล่น" เลือกชั้น > สร้างห้อง > ได้รหัส 4 หลักให้นักเรียน
3. นักเรียนเข้า index.html กรอกชื่อ-สกุล/ชั้น/เลขที่ > ยืนยัน > ชื่อเล่น + รหัสห้อง
4. แท็บ "กระดานสด": ดูสถานะ คลิกการ์ดเพื่อส่งข้อความ/เพิ่มหัวใจ/เพิ่มสิทธิ์ช่วยเหลือ
5. เล่นจบ กด "บันทึกลง Google Sheets" ระบบสร้างชีตใหม่ เทียบกับรายชื่อชั้น (มา/ขาด) — "ลา" ครูแก้ในชีตเองได้ (มี dropdown)
6. แท็บ "ที่บันทึกแล้ว": เปิดชีต / ลบ

## กติกาเกม
- 3 ภารกิจ (LV.1 เข้าถึง, LV.2 เพิ่ม/แก้ไข, LV.3 ลบ) ภารกิจละ 3 ด่านย่อย
- แต่ละ LV มี 5 หัวใจ (รีเซ็ตเมื่อขึ้น LV ใหม่) หมด = เริ่ม LV นั้นใหม่ตั้งแต่ด่านแรก
- ขอความช่วยเหลือได้ LV ละ 1 ครั้ง (ครูเพิ่มให้ได้)
- คะแนน LV ละ 100 (ผิดหักด่านละ 4, ใช้ความช่วยเหลือหัก 4) | LV.3 มีจับเวลา
- อันดับ: คะแนนรวมมากสุด เท่ากันใครเสร็จก่อนอยู่บน
